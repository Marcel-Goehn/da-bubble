# DA Bubble

Monorepo: `frontend/` (Angular 22) and `backend/` (Spring Boot 4.1.1).

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `Marcel-Goehn/da-bubble`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and `docs/adr/`, shared by frontend and backend. See `docs/agents/domain.md`.
