# Design exports

PNG exports of the DA Bubble Figma, so agents can read the design without Figma access.

Figma: https://www.figma.com/design/xQSIqpJwAEhYIsSjoVBNcL/DABubble--Slack-Clone---Copy-?node-id=117-2933

**The Figma is fixed**: v1 is exactly what these frames show.

## Layout

One folder per area. Full screens are 1x exports with the Figma frame's order prefix (`01-Log In.png`); reusable components and their states are 2x exports (`… component@2x.png`).

- `general/`: logo, shared buttons, imprint/privacy footer links
- `log-in/`: intro animation, log-in screen and its inputs
- `sign-up/`: sign-up screen and its inputs
- `avatar/`: avatar selection after sign-up
- `password-reset/`: request email, reset password, the reset email
- `main-application/`: workspace views (channels, direct messages, threads, editing messages) and their components
- `impress/`, `data-protection/`: legal pages
